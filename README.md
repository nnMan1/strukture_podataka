## Domaći zadatak: Automated Minesweeper & Data Analysis
Dear Students Ulysseus - COIL - Montenegro - Seville,
We are excited to announce a unique opportunity to participate in a collaborative project between our two universities. This initiative is designed to simulate a real-world software engineering environment where cross-institutional teamwork is essential.  
 
### Project Overview
This project challenges you to transition from being a Game Developer to a Data Scientist. You will work in groups to:  
Milestone 1: Build the core logic of an "Intelligent" Minesweeper game using matrix traversal and custom data structures.  
Milestone 2: Design an automated simulation system where AI "Bots" play autonomously and generate a large telemetry dataset in CSV format.  
Milestone 3: Analyze that dataset using the Java Collections Framework and the Streams API to extract high-value statistical insights.  

### Institutional Strengths & Collaboration
This project has been designed to leverage the specific expertise of each university:
University of Montenegro: Will lead the way in the design and implementation of low-level Data Structures (custom Stacks, Linked Lists, and Nodes).  
University of Seville: Will focus on the Definition of Types (OOP design) and the advanced use of the Java Streams API for data processing.  

### Logistics & Communication
To facilitate your work, we have set up several tools:
Teams: Your assigned groups are already available in the Teams channel.
Communication: We encourage you to use the Teams forums and private channels for daily coordination. Additionally, you may contact your teammates via the provided student emails.
Support: Any questions or technical issues should be posted in the shared Teams space, where both professors and students from both universities will be active.

### Important Dates
Initial Deadline: May 19th (this may be extended depending on the evolution of your work).
Control Session: During the week of May 19th, there will be a mandatory progress review session held during regular class hours at each respective university.
Please find the full project documentation attached here. We look forward to seeing the innovative solutions and strong teamwork that come out of this collaboration!
